# 地毯修复工单台（纯前端）

手工地毯修复工作室的工单管理台。React + Vite + TypeScript，无后端，数据仅存浏览器 `localStorage`。

## 功能

- **工单录入**：产地、年代、结密度、染色类型、破损区（在局部标记图上点击定位）、补线色、预估工时与标准修复工序。
- **一破损区一负责人**：每个破损区只能派给一名修复师，支持派工 / 改派 / 撤回。
- **批量派工整批校验**：在「批量派工」页勾选待分配破损区并指定修复师，提交时按每人周工时上限汇总校验（现有排期 + 本批工时）。**任一人超限则整批拒绝**，破损状态与人员排期保持不变。
- **离岗规则**：修复师离岗后，未开工单自动回到待分配；已开工单保持锁定（负责人保留），不能勾选工序、不能记完工，返岗后继续。
- **同步筛选**：产地 / 状态 / 关键词筛选同时驱动局部标记图、破损区列表与进度统计，不符合条件的标记淡显。
- **工序进度**：六道标准工序（清洁除尘 → 基底加固 → 经线修复 → 补线织造 → 纹样补色 → 平整整理），全部完成方可记完工。
- **数据本地化**：所有数据存于浏览器本地（键名 `rug-workbench-v1`），可一键重置为演示数据。

## 本地运行

```bash
npm run dev
```
